# Snat's Simple FFXIV's Overlay

A lightweight web-based overlay for Final Fantasy XIV. The idea of the overlay is for those who want a full-screen overlay to use within a web browser. Designed to be used as a local browser.

## Features

- Lightweight and self-contained.
- Simple customisation via CSS and JavaScript.

## Requirements

- A web browser.
- It is **NOT** designed to be overlaid over Final Fantasy XIV.

## Quick start

1. Point your overlay host at `index.html` or use https://snatmte.github.io/FFXIV-Overlay/
2. Open `index.html` in a browser for quick testing.
5. For testing, try demo mode by opening `index.html?demo` (or append `?demo` to your overlay URL). This pre-fills the DPS panel with characters and random DPS values.

## Files

- `index.html` — Main overlay markup.
- `overlay.css` — Styles and layout.
- `overlay.js` — Overlay behaviour and logic.
